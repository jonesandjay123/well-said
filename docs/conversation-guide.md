# 台詞怎麼聊

使用者提供的概念截圖用來說明討論選項：原話、對象、態度、古風程度、當下情境。日常互動直接在 ChatGPT 聊天中完成，這些條件可以用一句口語一起說出來。

## 條件與探索方向一起使用

**條件決定這輪台詞要符合什麼；探索方向提供不同的表達可能。**

- 對象：朋友、伴侶、長輩、同事、對手、陌生人等。依實際關係調整分寸，不只看稱呼。
- 態度：略帶調侃、溫柔體貼、不卑不亢、冷淡高傲、含蓄諷刺、機智幽默等；可混合、自訂或指定程度。
- 古風程度：現代精煉、半文半白（預設）、濃厚文言。這與友善、冷淡或諷刺是不同的事。
- 原話與情境：決定不能走偏的原意；如果故事已經說清楚，就不用再補一遍原話。

保留「極簡、溫雅、機智、半文半白」四種探索方向。它們不是完全獨立的四條刻度，也不是互斥的選項：極簡關乎篇幅與節奏，溫雅關乎措辭，機智關乎巧思，半文半白關乎古韻。可以組合成「極簡＋機智」或「溫雅＋半文半白」。

古風程度中的「半文半白」與同名探索方向有重疊，直接承認即可，不必另造一套名詞。平常在共同條件下提供五句，涵蓋相容的方向，並補一句適合當下的自由版本。明確設定優先：要求全用現代口語時，不必硬湊半文半白；想比較語體時，再另外給跨程度版本。

## 一輪示意

以下沿用概念截圖的情境，候選台詞是本次文件整理新寫的示例，並非使用者已選擇的句子。

> 朋友的辦法不算完美，但我願意先照做。略帶調侃、半文半白，給我五句。

這輪：朋友／略帶調侃／半文半白；保留「辦法不完美，但願意先採用」的原意。

| 探索方向 | 候選台詞 | 差異與提醒 |
| --- | --- | --- |
| 極簡 | 不算妙，姑且一試。 | 乾脆，輕輕保留評價。 |
| 溫雅 | 雖未盡善，倒也不妨一試。 | 較有分寸，調侃感很淡。 |
| 機智 | 妙計還差些，倒也能一試。 | 玩笑落在辦法上，仍願意試。 |
| 半文半白 | 此計未盡妙，姑且依你一回。 | 古韻較明顯；「依你一回」有熟人間的讓步感。 |
| 機智＋半文半白 | 法子還欠些火候，姑且一試。 | 用火候作比喻，輕點不足，不評論對方能力。 |

整理者會推薦第一句：短、保留原意，也沒有把玩笑加重成嘲諷。若覺得第一句不夠有古韻，第四句提供另一種選擇。這只是示意判斷，不代表使用者偏好。

## 接著聊，不必重來

可以接著說：

- 「第二句保留溫雅，再短一點。」→「未盡善，亦可一試。」其他條件沿用。
- 「這次全用現代精煉。」→ 改語體，例如「不算完美，先試試吧。」不再硬套古風。
- 「換成對長輩講，溫柔一點。」→ 更新對象與態度，保留辦法未完美但願意試的意思。
- 「同一句，幫我比較三種古風程度。」→ 此時才跨語體比較，分別標明。

使用者只調整某句時，聚焦那句，不必重新展開五句；只有要求多個候選時才再擴寫。換新情境時重新理解態度，不把上一輪的調侃自動帶過去。

## 批次收錄時保留什麼？

把原意、對象、目標態度、古風程度及後續修改一起留在條目，讓人看得懂「為什麼這句適合」。指定的態度與各句實際語氣分開：例如使用者要「略帶調侃」，某句卻偏酸，應標記偏離與風險，不能倒推使用者想諷刺。

同情境的不同輪次可在「台詞版本」下分組，寫清楚各組的設定及來源；不要用最後一輪設定覆蓋前幾輪。收錄時保留實際產生的數量，原討論四句就收四句，不為湊五句改寫歷史。
